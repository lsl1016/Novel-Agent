# Novel Agent V0.10 架构

系统有两条驱动路径(详见 `docs/agent-paths.md`):外部 Agent 经 skill + MCP 逐工具驱动(下图),或无人值守长跑(drive.py)进程内直调 NovelService——两条路径共享同一状态与门禁,内置四个模型本身不接触工具,只接收编译好的上下文。

        │
        ▼

        ▼

        ▼

## 隔离边界

1. **故事图 vs 参考图** — 参考数据永远不会自动成为新故事的正典(Canon)。
2. **世界真相(作者独有) vs 读者/视角(POV)知识** — 写作者上下文无法看到作者独有的真相。
3. **规划 vs 草稿 vs 正典** — 未来意图与草稿在定稿(finalize)之前均为非正典。
4. **规划器 / 写作者 / 审校者上下文** — 三者以不同的权限与预算独立编译。
5. **运行控制器保持有界** — 检索不会改变人在回路(HITL)或提交闸门(Commit Gate)的语义。
